# 아들맘 블로그모임 회원 특별 이벤트 · 숏드라마 제작 과정

블로그 ‘블로그 글쓰기 모임’(운영자 아들맘) 회원을 위한 숏드라마 제작 과정 안내 페이지예요. 진행은 제레미(AI빌더스랩)가 맡아요. **초안**이에요.

과정은 세 가지로 나뉘어요.

- **무료 강의 2회** (회당 2시간, 수업료 무료): 1회차는 그록봇과 Aside 설치·기초 활용, 2회차는 hyperframeshorts로 정보형 쇼츠와 짧은 숏드라마 장면 만들기. 4회·8회 과정의 선수 수업. 그록봇용 X Premium은 1회차에서 본인 구독.
- **1달 4회 과정** (주 1회 × 4주, 회당 2시간): 선수 수업은 무료 1·2회차. 결과물은 숏드라마 1화와 채널 업로드.
- **1달 8회 과정** (주 2회 × 4주, 회당 2시간): 선수 수업은 무료 1·2회차. 결과물은 숏드라마 1~2화, 정보형 쇼츠, 채널 운영 루틴.

장소는 동탄 실리콘앨리 B동 1529호(주차 지원)예요. 요일·시간은 추후 안내하고, 신청은 아들맘님께 해요. 수강료는 별도 협의예요.

## GitHub Pages로 공개하기
1. 이 폴더 내용을 저장소 루트에 올려요.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 골라요.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 열려요.

검색 노출을 원하면 각 HTML의 `<meta name="robots" content="noindex">`를 지워요.
