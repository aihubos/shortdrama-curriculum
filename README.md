# 아들맘 블로그모임 회원 특별 이벤트 · 숏드라마 제작 과정

블로그 ‘블로그 글쓰기 모임’(운영자 아들맘) 회원을 위한 숏드라마 제작 과정 안내 페이지예요. 진행은 제레미(AI빌더스랩)가 맡아요. **초안**이에요.

- 주 1회 × 4주, 총 4회 · 회당 2시간 · 오프라인 (요일·시간 추후 안내)
- 장소: 동탄 실리콘앨리 B동 1529호 (주차 지원 가능)
- 1회 설치 수업 무료 (그록봇용 X Premium은 본인 구독)
- 신청: 아들맘님께 별도 신청
- 수료 결과물: 내 유튜브 쇼츠 채널에 올라간 숏드라마 1화

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 1달 4회 과정 안내 페이지 (단일 파일, 외부 추적 없음, Pretendard CDN) |
| `curriculum_1달.md` | 1달 4회 커리큘럼 |
| `v2-8회.html` | 이전 8회 버전 페이지 |
| `curriculum_8회.md` | 이전 8회 커리큘럼 초안 |
| `v1-4회.html` | 더 이전 4회 버전 페이지 |
| `curriculum_4회.md` | 더 이전 4회 커리큘럼 (`curriculum.md`와 같음) |
| `assets/` | 예시 결과물 이미지·영상 |
| `preview-*.png` | 화면 미리보기 (배포에 꼭 필요하지 않음) |

## GitHub Pages로 공개하기
1. 이 폴더 내용을 저장소 루트에 올려요.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 골라요.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 열려요.

검색 노출을 원하면 `index.html`의 `<meta name="robots" content="noindex">`를 지워요.
